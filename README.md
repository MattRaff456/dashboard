Introduction:
This project's main purpose was to get some experience with unfamiliar concepts. APIs and GUIs were some of those concepts. The program has 2 python files, but the one that should be run is visual.py. By running it, you receive a dashboard with three buttons that correspond to three different things. You get the weather's temperature and description for West Chester, PA when you click the weather button, but you can change that easily. The second button creates a graph of certain stocks based on their data in the last six months. You can easily change the stocks. The third button is a textbox that you can clear, or submit a Marvel character to get information about them.

Interface Design:
Errors are handled with the try-catch statements. There might be one portion of the code that I forgot to implement this in, but it overall works great. The only input from the user are clicks and strings.
